\checkin{08/19} If $f(x)$ is a relation with $f(2)= 9$ and $f(7)= 9$, then $f(x)$ cannot be a function. \pspace

\sol The statement is \textit{false}. Recall a function is a relation such that for each input, there is only one possible output (though that output can be repeated by other inputs). That is, we can think of a function as a `coherent set of instructions.' Given an input, is there a single, unambiguous output? We know $f(2)= 9$ and $f(7)= 9$. There is no confusion as to what the output for $f(x)$ is for $x= 2, 7$. In fact, $f(x)= 9$ and $f(x)= x^2 - 9x + 23$ are both functions with $f(2)= 9$ and $f(27)= 9$. \par\vspace{1.3cm}



% 08/20
\checkin{08/20} \textit{Every} linear function must have a constant average rate of change. \pspace

\sol The statement is \textit{true}. This is one of the equivalent conditions for a function $f(x)$ to be linear, along with $f(x)$ having the form $f(x)= mx + b$ and $f(x)$ having a graph that is a line. In fact, we can see that a linear function has a constant average rate of change. Given any distinct values $x_1, x_2$ and linear function $f(x)= mx + b$, the average rate of change of change on the interval containing $x_1, x_2$ as endpoints is\dots
	\[
	\dfrac{f(x_2) - f(x_1)}{x_2 - x_1}= \dfrac{(mx_2 + b) - (mx_1 + b)}{x_2 - x_1}= \dfrac{mx_2 + b - mx_1 - b}{x_2 - x_1}= \dfrac{mx_2 - mx_1}{x_2 - x_1}= \dfrac{m(x_2 - x_1)}{x_2 - x_1}= m 
	\]
So, the average rate is constant and equal to the slope of $f(x)$ --- $m$. \par\vspace{1.3cm}

\checkin{08/24} If $f(x)= x + 3$ and $g(x)= 5$, then $(f \circ g)(0)= 15$. \pspace

\sol The statement is \textit{false}. Observe that $(f \circ g)(0)= f \big( g(0) \big)= f(5)= 5 + 3= 8$. Recall that the notation `$\circ$' is function composition---not function multiplication. The mistake here is that `$\circ$' is treated as multiplication: $(f \circ g)(0) \neq (fg)(0)= f(0) g(0)= (0 + 3) \cdot 5= 3 \cdot 5= 15$. \par\vspace{1.3cm}



% 08/25
\checkin{08/25} If the average rate of change for a function $f(x)$ on $[-1, 0]$ and $[0, 3]$ are both $5$, then $f(x)$ must be linear. \pspace

\sol The statement is \textit{false}. For a function $f(x)$ to be linear, it must have a constant average rate of change on \textit{every} interval---not just a few. For instance, the function $f(x)= \tfrac{3}{2} x^3 - 3x^2 + \tfrac{1}{2} x + 5$ has an average rate of change of 5 on $[-1, 0]$ and 5 on $[0, 3]$ but $f(x)$ is not a linear function. Of course, there are linear functions with an average rate of change 5 on $[-1, 0]$ and $[0, 3]$. For instance, $f(x)= 5x$ has an average rate of change of 5 on \textit{all} intervals---including $[-1, 0]$ and $[0, 3]$. However, again, to be a linear function, $f(x)$ must have a constant average rate of change on \textit{every} interval. There are functions that have an average rate of change of 5 on infinitely many intervals but are still not linear. For instance, $f(x)= 5x + \sin(2\pi x)$ is not linear but has an average rate of change of 5 on all intervals of the form $[n, n + 1]$, where $n$ is an integer, i.e. $[-4, -3]$, $[0, 1]$, $[9, 10]$, etc. We can see this: observe $\sin(2\pi a)= 0$ for all integers $x= a$ and\dots
	\[
	\dfrac{f(n + 1) - f(n)}{(n + 1) - n}= \dfrac{\big(5(n + 1) + \sin(2\pi(n+1)) \big) - \big(5n + \sin(2\pi n) \big)}{n + 1 - n}= \dfrac{(5n + 5 + 0) - (5n + 0)}{1}= \dfrac{5}{1}= 5
	\] \par\vspace{1.3cm}



% 08/26
\checkin{08/26} The function $f(x)= 3(x + 5)^2 - 6$ is quadratic with vertex $(5, -6)$ and has a maximum possible output. \pspace

\sol The statement is \textit{false}. The function $f(x)$ is clearly quadratic, as expanding yields $f(x)= 3x^2 + 30x + 69$, which is quadratic. Alternatively, we see that $f(x)$ has the vertex form of a quadratic function, $a(x - P)^2 + Q$, where $a$ is the $a$ from the standard form of a quadratic $ax^2 + bx + c$ and $(P, Q)$ is the vertex of the quadratic function. Observe $f(x)= 3(x + 5)^2 - 6= 3 \big(x - (-5) \big)^2 + (-6)$ is in vertex form with $a= 3$, $P= -5$, and $Q= -6$. Therefore, the vertex is $(-5, -6)$---not $(5, -6)$. Moreover, because $a= 3 > 0$, the quadratic function opens upwards so that it has a minimum possible output (namely, the $y$-coordinate of the vertex, $-6$) but no maximum possible output. \par\vspace{1.3cm}



% 08/27
\checkin{08/27} A quadratic function $f(x)$ has a $y$-intercept, two $x$-intercepts, and either a maximum or a minimum output. \pspace

\sol The statement is \textit{false}. We know that a quadratic function is defined everywhere. So, $f(0)$ is defined. But this is precisely the $y$-intercept for $f(x)$. We know that each quadratic function has either a maximum value (if $a < 0$ so that the quadratic function opens downwards) or a minimum value (if $a > 0$ so that the quadratic function opens upwards). However, not all quadratic functions have two $x$-intercepts. By the Fundamental Theorem of Algebra, a quadratic (polynomial of degree 2) has either none, one, or two $x$-intercepts. For instance, $f(x)= x^2 + 1$ has no $x$-intercept (simply choose any quadratic with a vertex in Quadrant~I or Quadrant~II that opens upwards---$a>0$---or any quadratic with a vertex in Quadrant~III or Quadrant~IV that opens downwards---$a<0$), $f(x)= x^2$ has a single $x$-intercept ($x= 0$), and $f(x)= (x - a)(x - b)$ has two $x$-intercepts ($x= a, b$)---so long as $a \neq b$, e.g. $f(x)= (x - 1)(x + 1)= x^2 - 1$. \par\vspace{1.3cm}
